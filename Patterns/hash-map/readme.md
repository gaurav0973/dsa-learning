# Hash map

## When to use

Use when you need **counts**, **last-seen indices**, or **complement lookups** (e.g. two-sum style) in O(n) average time. Clues: "frequency", "how many times", "find pair with sum/target", counting without needing O(1) space optimization. Trade-off: O(n) extra space for the map.
